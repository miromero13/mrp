Industrial Material Requirements Planning (MRP) and production scheduling system to optimize supply chains, bill of materials (BOM), inventory replenishments, and assembly lines.

---

## 🏛️ Architecture

- **`frontend/`**: Enterprise single-page application built with **Angular**, Vite, and Tailwind CSS.
- **`backend/`**: Transactional domain service built with **Spring Boot** and **Kotlin** using Gradle.

---

## 🚀 Getting Started

```bash
# Backend (Spring Boot)
cd backend && ./gradlew bootRun

# Frontend (Angular)
cd frontend && npm install && npm run start
```
